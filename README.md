# Simulador de CBS e IBS · DriveData

Versão aberta do simulador da Reforma Tributária do Consumo feito pela DriveData sobre o Microsoft Fabric.

Calcula CBS e IBS com as regras e tabelas da Calculadora de Tributos que a Receita Federal publicou no GitHub
([calculadora-rtc-regime-regular](https://github.com/ReceitaFederal/calculadora-rtc-regime-regular), licença MIT)
e projeta a carga de uma empresa de 2026 a 2033.

Acesse: https://drivedata-repo.github.io/simulador-rtc/

Simulação para planejamento. Não substitui a apuração oficial.
